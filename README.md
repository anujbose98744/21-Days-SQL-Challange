# 21 Days SQL Challenge

This repository contains my solutions for the **21 Days SQL Challenge** organized by the **Indian Data Club**. The goal of this challenge is to strengthen SQL skills through daily practice problems covering topics like:

- Basic and advanced SELECT queries
- Joins, subqueries, and aggregations
- Data manipulation (INSERT, UPDATE, DELETE)
- Functions and window operations

Each day, I push my solutions to this repository, along with explanations and notes for learning and reference.
